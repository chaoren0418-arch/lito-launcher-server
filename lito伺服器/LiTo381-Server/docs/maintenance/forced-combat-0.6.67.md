# 0.6.67：Ctrl 強制指定目標

日期：2026-10-14。正式部署為 0.6.67，0.6.66 基準 ZIP 保持不變。

在遊戲世界按住 Ctrl 發出普攻或指定技能，可選取同場友方或敵方玩家，以及其召喚物。一般操作仍遵守模式／隊伍規則。此擴充只解除明確指定目標的敵友限制；範圍技能的其他友方目標仍遵循原規則。Pet Race 不套用此例外。

距離、視線、死亡、觀戰、冷卻、MP／材料消耗、技能條件及負面狀態成功率仍沿用原檢查。沒有變更地圖、守護塔座標、房主標記或資料庫。

## 接線

- 登入器 `native/forced_combat.h` 與 `.inc` 在原生送出點 0x4C6B27 包裝攻擊封包；僅目前前景遊戲、戰鬥狀態及 Ctrl 按住時附加版本化意圖。
- 追加內容為 `4C 46 43 31 <opcode> 01 67 A5`，更新封包長度後交回原有加密送出流程。無目標、座標及非物件型技能格式不追加。
- `ForcedCombat.java` 在 ClientSession 分派前驗證並移除擴充；只在該次請求內保存目標，finally 清除，避免後續一般攻擊沿用強制狀態。
- GameHub 原本拒絕的敵友判定，僅在同場且符合本次明確目標時允許。資料庫與原生資源不變。
- 現行建置入口 `tools/resource-database/build.py`；正式 JAR 相對 0.6.66 只變更 ClientSession、GameHub、ForcedCombat 及其 Intent 四個 class。

## 驗證

- 原生封包單元測試：Ctrl、前景、場景、物件 ID、技能格式及封包長度檢查通過。
- 真實 ClientSession 記憶體測試：普通友方光箭拒絕，Ctrl 光箭與普攻造成傷害；負面技能進入正常成功率與消耗流程；冷卻、距離、死亡、觀戰限制保留。
- 範圍技能：允許強制指定的友方主目標，未指定的鄰近友方不受波及；下一個一般請求沒有強制狀態殘留。
- 既有六項資源、房間、流程、清單、移動與移動鎖定回歸通過。
- 正式雜湊、200% 原生 resources_ready、送出 hook 載入與自有程序清理通過；見登入器 `docs/startup-smoke.json`。
- 尚待使用者以兩個原生遊戲視窗驗收 Ctrl 普攻、光箭及負面技能；自動測試不代表全部技能手動驗收完成。
