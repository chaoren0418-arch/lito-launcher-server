來源記錄對大量Layer8使用兩個明確field group，避免重複數萬次相同方法文字；lito_cand_lineage_group列出每個實際欄位，raw與policy/NULL不同組。仍可按表名＋主鍵＋欄位追溯，獨立驗證會展開群組並檢查完整覆蓋。例如查`lito_cand_map_effect`欄位raw_x：

```sql
SELECT p.*, s.path, s.member, s.sha256, s.version
FROM lito_cand_provenance p
JOIN lito_cand_source s ON s.source_id=p.source_id
LEFT JOIN lito_cand_lineage_group g
  ON g.target_table=p.table_name AND g.group_name=p.field_name
WHERE p.table_name='lito_cand_map_effect' AND p.primary_key='1'
  AND (p.field_name='raw_x' OR g.field_name='raw_x');
```

上述僅供日後審查讀取，候選SQL沒有匯入。重新提取受影響領域：

```powershell
python enrich_stage2.py --refresh-packets

```
