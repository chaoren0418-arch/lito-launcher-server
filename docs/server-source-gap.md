## 已驗證／推測／待驗證

- **已驗證**：`unzip -p reference/base-0.6.71.jar META-INF/MANIFEST.MF` 的 `Main-Class` 為 `local.lito381.server.SharedResourceMain`；`mvn package` 產物 MANIFEST 同樣寫入此 Main-Class，`Implementation-Version` 為 `0.6.71`。本清單由 `jar tf` 對兩個 JAR 的 `.class` 路徑做集合差。
- **推測**：標「刻意排除」的 inner／匿名類是 javac 對現行原始碼（T002 反編譯或 tools 原文）編出的形狀不同，不是少了一整個頂層型別。
- **待驗證**：類別清單一致不等於位元組碼／行為一致；未跑 `1.啟動伺服器.bat --check`／`--smoke`，未連正式 DB，未啟動遊戲。
