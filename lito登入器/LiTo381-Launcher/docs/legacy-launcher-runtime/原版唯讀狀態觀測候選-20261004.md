## 輸出欄位與判讀

JSON 根為 observer 的 `schema_version=1`，含 `pid/executable/created_filetime`、開始／結束時間、唯讀權限、limits、status 與 samples。每筆為 `elapsed_seconds/status/fields/read_errors/read_calls/bytes_requested`。

| fields | 精確來源 | 判讀限制 |
| --- | --- | --- |
| version_ready | byte_75F754，1 byte；S_VERSION 成功分支 004A34AC | ready byte 的實際值；不改它，不等於 callback 已進入 |
| input_enabled | byte_75F6E5，1 byte；496200／4962B0 gate、495E40 設值 | 可與 Confirm 時間對照；不證明 Windows 輸入送達 |
| cached_login | byte_75F755，1 byte | 初次手動登入通常 0；不自動設定 |
| client_mode / server_protocol_version | 64BBD4／63D54C，各 4 bytes | 狀態欄位；boot 早期的 0 不等於錯誤 |
| screen_root_present / page | 75F6E8 的存在性，及 root+0C 的頁碼 | 不輸出 root 值；不可讀為 null。偵測 root 改變後清除動態頁／focus 結果 |
| focus_present / enter_focus_matches_first_edit | focus 64149C 與 page 0 的 `[root[0]+4]` 關係 | 僅 mode 2／page 0 讀三個結構 scalar；不輸出 pointer，不跟入 edit widget／內容，不等於 Confirm callback 執行 |
| input_modifier_gate | byte_64B6DC，1 byte；496200 對值 3 的 Enter/Tab 前置分支 | 尚需實體按鍵證據才能判定該分支影響 |
| wm_close_gate / sys_close_gate | byte_64BC04／64BBE8，各 1 byte | close 分支前置旗標；沒有收到 WM_CLOSE／SC_CLOSE 的事件證明 |
| shutdown_state | dword_62C9C4，4 bytes | 原版不同路徑有 1／2 等寫入；不單憑值判 clean exit |
| key_handler / mouse_handler / render_handler | off_62C9B8／BC／C0，各 4 bytes | 證明指標值，不證明 callback 已執行 |
| page_focus_status | 固定枚舉 | 例如 observed_login_relation、root_absent、page_unreadable、non_login_page、root_changed_or_unreadable |

RPM 必須完整返回該 scalar 寬度；短讀為 `unreadable_or_partial`，例外為 `read_failed`，值是 null，不以 0 代替，也不把 exception message／raw bytes 放入證據。動態 pointer 需 x86 合法範圍／對齊，拒絕已知帳密 cell 區間；只讀 root 的 page／table 及 table 的第一 edit pointer，不讀 edit 本體、完整表單、stack、帳密或帳密 hash。各 RPM 非原子，只能偵測 root 前後改變，不能消除所有瞬時 race。

結束 status 包括 sample_limit_reached、duration_limit_reached、observed_process_exited、mapping／identity 拒絕。只有在等待 handle 顯示原版已退出時才記 `observed_exit_code_hex`；非零 code 不自動分類為正常或 crash。採樣已到限而原版後來退出，須以原版啟動報告補足。
